### How I work on GitHub

- **Reproducible**: pinned dependencies, data downloaded and checked by hash or shipped with its licence, one command to rerun the analysis.
- **Tested**: unit tests, and tests that recompute the figures quoted in each README.
- **Automated**: GitHub Actions CI on every push (lint, tests, notebook or SQL runs).
- **Clean history**: small commits with [Conventional Commits](https://www.conventionalcommits.org/) messages, no secrets in the repository (`.gitignore`, credential files excluded).
